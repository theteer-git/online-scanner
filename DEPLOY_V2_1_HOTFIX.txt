- Old V1 interface still being served

DEPLOYMENT

1. Extract this ZIP.
2. Copy every extracted file into D:\cam and replace existing files.
3. Keep D:\cam\.git unchanged.

Then run:

cd /d D:\cam
git add .
git commit -m "Fix background remover WASM backend and stale V1 route"
git push

Wait until the Cloudflare Pages deployment is complete.
