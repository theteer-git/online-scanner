BACKGROUND REMOVER V10.4 — TRUE FAST ENGINE

Root cause fixed:
V10.3 labelled MODNet as Fast, but the model was explicitly loaded as
fp32. That forced the full-precision model and slow CPU inference.

V10.4 changes:
- MODNet dtype changes from fp32 to q8.
- The selected q8/uint8 weight is approximately 6.63 MB.
- Cloudflare Pages sends COOP/COEP headers.
- Compatible browsers can use multithreaded ONNX WASM.
- Runtime diagnostics show isolation and thread count.
- MVANet Quality mode remains optional.
- DETR remains limited to Person + support.
- No model preloads before the user starts.

DEPLOY

1. Extract this ZIP.
2. Copy all files into D:\cam and replace existing files.
3. Keep D:\cam\.git unchanged.
4. Ensure D:\cam\_redirects does not exist.

Run:

cd /d D:\cam
git add -A
git commit -m "Use quantized multithreaded MODNet for true fast mode"
git push

After Cloudflare deployment:

node verify-background-remover.mjs

Open:

https://online-scanner.pages.dev/background-remover?v=10.4.0
