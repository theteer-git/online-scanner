BACKGROUND REMOVER V10.3 — SPEED-FIRST ENGINE

Why V10.3:
MVANet q8 WASM is accurate but slow on ordinary desktop hardware.

Changes:
- Fast mode is now the default.
- Fast mode uses MODNet WASM.
- Quality mode uses MVANet only when explicitly selected.
- DETR Panoptic loads only when Person + support is selected.
- Automatic MVANet startup warmup has been removed.
- Loaded models are still reused during the tab session.
- Existing geometry cleanup remains in place.
- No paid API, upload, or image storage is introduced.

Expected behaviour:
- Ordinary Person-only extraction should complete much faster.
- Quality mode remains slower by design.
- Person + support remains the heaviest mode.

DEPLOY

1. Extract this ZIP.
2. Copy all files into D:\cam and replace existing files.
3. Keep D:\cam\.git unchanged.
4. Ensure D:\cam\_redirects does not exist.

Run:

cd /d D:\cam
git add -A
git commit -m "Make fast MODNet processing the default"
git push

After Cloudflare deployment:

node verify-background-remover.mjs
